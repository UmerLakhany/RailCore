# ZongoBites

A Node.js backend project using Express, TypeScript, and Prisma ORM.

## Setup

1. Install dependencies:
   ```sh
   npm install
   ```
2. Copy `.env.example` to `.env` and set your environment variables (e.g., `DATABASE_URL`).
3. Build the project:
   ```sh
   npm run build
   ```
4. Start the server:
   ```sh
   npm start
   ```

## Scripts
- `npm run dev` — Start in development mode
- `npm run build` — Compile TypeScript
- `npm start` — Run compiled server

## Project Structure
- `src/` — Source code
- `dist/` — Compiled output
- `.env` — Environment variables
